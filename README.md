The Midnight Vault — a top-down stealth heist game in three museum rooms. Slip past patrolling guards and sweeping security cameras, read their vision cones, spend coins on distractions, smoke and EMPs, steal every relic, and reach the getaway van before the alarm fills. Keyboard and mouse, no build step, no network requests: plain static files under game/.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Play: WASD / arrows to move, Shift to sneak, click to toss a coin, 2 for smoke, 3 for EMP, M to mute, P to pause.
